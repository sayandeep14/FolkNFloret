# Folk & Floret film assets

The website's photoreal cinematic mode will read its generated footage from
this directory.

Use the exact names below:

```text
01-estate-aerial-web.mp4
02-field-flight-web.mp4
03-curation-atelier-web.mp4
04-candle-lighting-web.mp4
05-couple-date-web.mp4
06-night-garden-finale-web.mp4
```

Portrait versions belong in `mobile/` and poster frames belong in `posters/`.

See [`docs/VEO_CINEMATIC_PRODUCTION_BIBLE.md`](../../docs/VEO_CINEMATIC_PRODUCTION_BIBLE.md)
for generation prompts, continuity rules, encoding specifications, and the
scroll integration map.
